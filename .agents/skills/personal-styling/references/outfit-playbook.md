# 三套穿搭工作手册（中国本土男装场景）

## 决策次序
场景/着装要求 → 用户真实偏好 → 版型/体感 → 颜色和面料 → 复用旧衣 → 新购清单和预算 → 发型与配饰。

## 固定三套逻辑
- A **日常高频款**：最舒适、耐穿、容易打理，适合大部分工作日。重要的是用户能穿得出去。
- B **形象提升款**：更正式、挺括、干净，适合讲课、重要会议、见客户和正式社交，但不要一律商务正装。
- C **清爽年轻款**：用浅色内搭、自然直筒、短夹克或低帮鞋增加轻盈感；日韩元素比例节制，不变偶像穿搭。

## 场景补丁
- 高校教学/科研会议：站立讲课舒适、上半身轮廓精神、不夸张，衬衫或 Polo 与直筒裤比硬性三件套往往更实用。
- 日常通勤：考虑气温、雨天、城市交通；鞋履好走、面料可护理。
- 约会聚会：在个人风格上精修细节，不追求商务正装式距离感。
- 旅行休闲：舒适、透气、易收纳，鞋子优先行走体验。

## 季节补丁
- 春夏：透气棉麻混纺、牛津纺、轻薄针织；不要在炎热环境无条件套叠厚外套。
- 秋冬：羊毛/混纺、针织和短外套做层次；关注当地实际天气，不凭月份机械推荐厚羽绒。

## 预算沟通
人民币预算是整套或单件？已知用户提法优先，不明确时按“整套预算”写并标注。价格只能是**粗略的预算分配计划**，不是真实在售标价。例：预算 800 元且鞋已有，可把大部分钱花在一条更合身的裤子和高频上衣上；若旧衣能满足，不强求全套重购。

### 未联网时可用分配思路（非商品价格）
- 上衣约 30%～40%。
- 裤子约 25%～35%。
- 鞋子约 20%～35%（有可复用鞋则转给裤装/上衣）。
- 配饰约 0%～10%，发型服务通常不包含在服装预算内。
权重只是参考，不是必须耗尽预算。

## 现实购衣核验
建议用户试穿或向商家核实：肩线、衣长、胸围余量、臀围和裆部活动余量、腰围、裤长、鞋楦和脚感；不同品牌尺码不通用。勿凭照片直接给出准确码数。

## 发型输出模板
发型方向：自然侧分 / 纹理短发 / 轻薄刘海短发 / 修整两侧的中短发等。
理发沟通语示例：“两侧清爽但不要推得太高，顶部保留自然层次，额头露一点但不要全部露出，尽量不用大量发蜡；请按实际发旋与发质调整长度。”
仅用户提供发质、发量、发际线等信息时才能对这些因素做具体判断。给一个低维护方案和一个略精致方案，如照片信息不足，建议到理发店与理发师现场确认。

## 默认输出结构（可根据用户问题简化）
1. **目标与观察**：本次场景、目标气质、可见信息与限制。
2. **适配原则**：2～3 条针对个人的建议。
3. **三套完整方案**：
   - 名称、适用场景、上衣、裤子、鞋子、配饰、发型、配色、版型细节、为什么。
   - 购买优先级：能复用哪些衣物，可能需要补什么。
4. **理发店可直接复述的一句话**。
5. **需要实际试穿核实的两三项**。
不要为没有图片、没有实物评价、没有真实报价的方案编造“95分”“完美适合”等量化结果。
