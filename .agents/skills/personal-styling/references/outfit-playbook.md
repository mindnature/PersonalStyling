# 有差异、可穿着的三套穿搭生成法

## 先解决具体问题，后挑潮流
输入可以是照片、用户文字、衣柜清单或混合。默认决策次序：
**场景/真实气候 → 个人目标 → 可见版型问题 → 现有单品 → 颜色/面料 → 采购预算 → 配饰与发型**。

## A/B/C 必须差异明确

| 方案 | 设计任务 | 推荐变化 | 避免 |
|---|---|---|---|
| A 日常高频 | 多数工作日可以重复穿、耐打理 | 舒适面料、自然肩线、可走路的鞋 | 造型过分正式 |
| B 形象升级 | 会议、公开发言、正式社交 | 比 A 增加一点挺括/结构、提升领口或鞋履精致度 | 为了稳重变成全套正装 |
| C 清爽年轻 | 课余、朋友聚会、轻商务休闲 | 比 A 增加轻盈色彩、层次或更休闲的鞋、自然发型 | 厚刘海、极宽落肩、夸张韩团风 |

**至少两项实质差异**：例如 A 牛津纺衬衫＋直筒裤＋简约运动鞋，B 轻结构外套＋单褶裤＋乐福鞋，C 短款针织 Polo＋直筒牛仔裤＋德训鞋。若预算不允许多买，每套可复用同一单品，通过不同领型、叠穿、卷袖、扎衣和适用场景拉开差别；不能为了差异牺牲预算。

## 适配中国真实生活

- **高校讲课/科研会议**：衣服需适合站立、抬手写板书、走动；有领单品或挺括外套是候选，不是硬规则。冬天兼顾室内外温差。
- **办公室/通勤**：考虑城市气温、湿度、雨天和交通方式；鞋耐走、裤子活动舒适。
- **约会/社交**：保留个人风格，合适的面料与鞋比盲目堆叠昂贵配饰更重要。
- **旅行/户外**：出汗、收纳、风雨和行走体验优先。
- **岭南及闷热地区**：秋冬可能仍适合轻薄衬衫/针织；没有实时天气就不要武断建议厚大衣。
- **寒冷北方地区**：室外保暖与室内可脱外层并重，不以“显瘦”牺牲温度。

## 三套的强制填写要素
每套填完再给用户，不能仅列“上衣+裤子+鞋”：
- 场景/关键词：这一套解决什么需求？
- 上衣：领型、内/外层、颜色、材质、肩线与衣长。
- 裤子：颜色、直筒/微锥/宽直筒、裤口与鞋面关系。
- 鞋子：类别、鞋体量、是否日常可走。
- 配饰：至多一两件有实际用途；也允许“无需新增”。
- 发型：可剪的顶部/两侧/刘海方向。
- 证据与理由：和照片可见线索或用户偏好挂钩，不写“因为高级”。
- 试穿动作：站立、坐下、抬手/行走至少提醒一处验证点。
- 来源：哪些现成衣物复用、哪些新增待购。
- 不确定处：用简短“待试穿验证”表达。

## 预算与真实购买
人民币“预算分配”只代表可接受的上限，不等于市场实时售价；把采购清单去重后计算总额。操作方法参考 @references/budget-and-wardrobe.md。推荐品牌型号和购买链接必须有真实、可核查的商品来源，不能凭印象捏造。

## 结果排序
**A 放在第一推荐**，除非用户的主任务是正式活动或其他特定场景。这是“最可能真正穿出去”的方案，而不是评分最高就推荐最贵的。
