# 安装后直接使用：示例与理想回答形态

## 1. 双照片：完整个性化方案
用户：“我上传了全身照和正脸照，日常高校讲课，有时开会，175 cm，穿 L，成熟感 70%＋少年感 30%，整套新增预算 800 元。已有深灰直筒裤和白鞋。”

**前提**：以下照片线索仅为教学假设，不能在实际没有看见照片时原样套用。假设照片显示“上衣下摆遮挡腰线”“裤脚在鞋面上有明显堆积”“刘海遮住额头”，且有真实图片可供观察。

理想回答的起点：
- 可见线索 1：现有上衣衣摆偏低 → 腰线视觉位置被遮住 → 先试稍短上衣或适度半塞衣摆。
- 可见线索 2：裤脚堆叠较多 → 直筒线条不够清楚 → 先用现有深灰裤试短一点的裤长，不直接给厘米数。
- 可见线索 3：当前刘海较厚 → 额头完全被覆盖 → 可以对比自然侧分和轻层次短发，不依据照片判断发质。

三套**明确有区别、又共享衣物**：
- A 日常高频：浅蓝牛津衬衫（适度挺括）＋现有深灰直筒裤＋现有白鞋＋无需新配饰；自然侧分短发。衬衫下摆不要压得过长，讲课抬手不紧绷。偏清爽有精神。
- B 形象升级：现有基础内搭＋轻结构藏蓝短外套＋现有深灰直筒裤＋在要求正式的会议时考虑更简洁的鞋（已有白鞋可先用）；露额自然短发。比 A 多一层结构、领口更稳重、正式度不同。
- C 轻盈休闲：米白针织 Polo＋现有深灰直筒裤＋现有白鞋；轻薄纹理短发。与 A 的衬衫领型不同，与 B 的外层正式度不同。

去重采购**预算目标**：浅蓝衬衫 ≤220 元、藏蓝外套 ≤350 元、米白 Polo ≤180 元、预留修改和运费 ≤50 元，合计 ≤800 元。数字是目标分配，**非经过实时核验的标价**。不要求为每套重复买裤/鞋。
理发店沟通：“两侧清爽但别铲太高，顶部保留自然层次，刘海减重并露一点额头，方便日常自然打理；按实际发旋和发质调整。”
用户真正上传什么照片，就根据**那个画面**修改，绝不能复制上述虚构观察。

## 2. 纯文字、无照片
“我不传照片，预算 600 元，办公室穿，想清爽不学生气。”

答案开头写“以下未基于照片分析”。给适宜当地季节的 2–3 套候选；不要说“你的脸型”“你的腿短”“你的肤色冷”。如果无天气数据，不做特定气温断言。

## 3. 只有脸照求发型
“这是我的正脸，适合什么发型？”

如果看得见：简述发型现状和额头遮挡，给第一候选+备选、两侧/顶部/刘海沟通语、打理程度。**不强行生成三套衣服**。看不见：明确未能读取，基于用户描述给候选，不装看到了照片。

## 4. 衣橱复用
“有两件白衬衫、一件深灰针织开衫、两条黑裤子和白鞋，别让我花钱。”

把清单当成真实已有；给至少三种穿法，允许 0 元新增，重点解释层次、鞋裤体量、场景差别；不要硬塞“必须买一件新夹克”。

## 5. 反馈修订
“你刚推荐的 B 太显老，不要改裤子和预算。”

先复述保留条件。指出可能造成正式度过高的具体因素，再只改 B 的外套/鞋/发型一两处，重算采购费用。**不能重写 A/C 或改变裤子**。

## 6. 照片生图或选购
- “按 B 给我生成本人试穿图”：只有宿主提供可用图像编辑工具并已获用户明确要求才调用；否则提供可复制提示词，不声称已生成。
- “找京东 500 元以下的裤鞋”：只有搜索到当前商品数据才报告售价与链接；否则给检索词与试穿核对项。

## 7. 高反差条件
- 广东闷热冬季：优先轻量可脱外套，而非机械厚大衣。
- 北方零下出行：保暖第一，室内脱外层后仍得体。
- 用户不喜欢日韩元素：即使默认是少量日韩简约，也必须按用户最新偏好删除，不进行争论。
- 用户讨厌裤装拘束：舒适活动范围优先，不为“显精神”强推过紧修身裤。
