# 使用示例（安装后直接发给宿主）

## 1. 全身照 + 面部照
“请使用 PersonalStyling 衣品选衣技能。我上传了全身照和正脸照，身高 175cm，日常穿 L，平时在高校讲课和参加会议。希望成熟感 70%＋少年感 30%，秋冬，整套预算 1000 元。分析照片可见的比例和发型，给我三套上衣、裤子、鞋子、配饰、发型完整方案。先考虑我已有的藏蓝外套。”

应该回应：可见/不可见分开；三套可执行方案；不编身材尺寸；发型话术；复用旧衣；预算约束。

## 2. 没有照片的第一轮
“我暂时不想传照片，男装通勤预算 600 元，想有点少年感，但别太学生气。”

应该回应：开头“未基于照片分析”；给可试穿的款式与配色，不凭空描述用户的脸型或体型。

## 3. 有照片但宿主无法视觉读取
“这是我的脸照，帮我看适合什么发型。”

应该回应：诚实说明当前无法查看图片，邀请用户换支持图片的入口或描述发型、额头露出程度和打理意愿；不能装作看到了照片。

## 4. 已有衣橱
“我有两件白衬衫、一件深灰针织开衫、两条黑裤子和一双白鞋，别让我买太多衣服，怎么搭适合日常上班？”

应该回应：优先重组已有衣服，指出可替换项，最多推荐关键补充单品，解释几套搭配的场景差异。

## 5. 想要本人试穿图
“按方案 B 给我生成一张我本人穿着的真实效果图。”

应该回应：工具可用时才生成，照片作参考并注明可能有偏差；不可用时提供明确的图像编辑提示词。不能把示意模特图说成用户本人。

## 6. 想找真实商品
“按这套帮我找京东能买到的裤子和鞋子，预算 500 元。”

应该回应：有实时搜索工具则核查并引用商品来源，无搜索则给类型、参数、检索词与避坑建议，明确不是已经验证的商品列表。
