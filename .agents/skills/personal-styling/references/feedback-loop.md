# 精准改款：用户反馈后仅改相关因素

每次修改都保留已确认的条件：用户本人、已有照片、场景、季节/气候、总预算、衣橱、用户认可的版型与单品。仅修改必要部分；默认不重新索要照片。

| 反馈 | 优先排查的因素 | 可以调整的变量 | 不应做 |
|---|---|---|---|
| “太显老”“像领导” | 西装硬挺程度、全身深色、皮鞋正式感、油亮发型 | 减少一处硬结构/换轻薄上衣/换自然发型或休闲皮鞋 | 用幼稚图案或夸张碎盖“装嫩” |
| “不够成熟” | 廓形、裤腿堆积、上衣材质、过多彩色 | 优化裤型、用更挺括面料、简化鞋包 | 直接套三件套西装 |
| “太韩”“像男团” | 厚重刘海、过大落肩、夸张叠穿/配饰 | 改自然侧分、正常肩线、减少层数 | 推翻中国主流审美定位 |
| “太宽松/显得没精神” | 肩线、衣长、裤脚堆叠 | 上衣缩短或换合身版、裤脚修短、减少堆积 | 按照片武断给精确尺码 |
| “看着不协调” | 上下体积、颜色数、鞋体量 | 优先改一处体积关系，重检裤口与鞋楦 | 只换色滤镜 |
| “预算超了” | 新增采购清单、重复项 | 去重、复用旧衣、砍最低优先级配饰/外套 | 把预算偷偷改成每套上限 |
| “已有衣服没用上” | 衣橱记录 | 指定至少一套使用已有单品，更新待购表 | 继续推荐完全重购 |
| “发型不像我” | 发旋、刘海、两侧长度、宿主图片编辑能力 | 给两个不改变面部身份的发型候选；模拟图重新检查 | 宣称生图和本人完全一致 |
| “不适合讲课/开会” | 场景正式度、舒适度、气温 | 校正领口、面料、鞋履、外套可穿脱性 | 忽略已知场景 |
| “色彩太沉闷” | 整体明度与颜色数量 | 替换一处中上身色块、保留其余结构 | 四件衣服全换色 |

## 修订回复模板
1. “保留的部分”：场景、预算、已认可的单品。
2. “问题在哪里”：最多两条可见证据或用户偏好。
3. “只改这些”：旧方案 → 新方案，说明差异与成本变化。
4. “修改后的穿搭”：给完整改版造型，旧衣/新购清单重新计算。
5. “还需试穿确认”：仅列与此次修改相关的一项。

用户说“整套重做”时才可大范围重设计，但也不能忘记已给出的个人照片和预算。
