# 预算与衣橱优先：拒绝三套重复付费

## 先判断“预算”的含义
- 用户说“预算 800 元”，默认是**本次实际需要购买的所有单品总额**，三套搭配可以共享鞋/裤子/上衣；不可暗中理解成每套 800 元 × 3。
- 用户明确“每套预算 800 元”，才按每套上限处理。
- 有鞋、外套等现有衣服且合适时，按 **0 元新增采购**计算；不虚构其原价。
- 商品尚未实时检索时，所有价位都是“预算目标/分配上限”，不是商家实际标价，实际下单必须核价。

## 先列出衣橱再推荐
按照上衣 / 外套 / 裤装 / 鞋 / 配饰 / 发型现状整理，至少给出：
- 可以直接用的：颜色、款式及搭配位置。
- 可以改进再用的：如缩短裤脚、熨烫、洗护、换鞋带，不自动推荐消费。
- 真正缺失的：三套方案共同依赖的高频核心单品优先。
- 不建议购买的：与现有衣物高度重复、频率低或预算效益差的项目。

## 示范：预算 800 元，有旧白鞋和深灰裤
下列数字是**采购计划上限**，不是查询过的实时售价。
- 浅蓝牛津纺衬衫：目标 ≤ 220 元。
- 米白薄针织 Polo 或短袖：目标 ≤ 180 元。
- 轻量深蓝外套：目标 ≤ 350 元。
- 留给必要的小修补/运费：≤ 50 元。
- 总新增支出上限：220 + 180 + 350 + 50 = 800 元；两件已有衣物计 0 元。
- A 用浅蓝衬衫＋灰裤＋白鞋；B 用深蓝外套叠白/浅蓝内搭＋灰裤＋白鞋；C 用米白 Polo＋灰裤＋白鞋。若三套仍过于相似，应在**无需花钱**的层次、领型、搭配场景上拉开，或优先修改一件旧单品。不要为了“凑三套”额外买更多东西。

## 预算紧张时
优先顺序通常是：明显不合身且使用频率高的裤子/上衣 → 能跨场景使用的鞋 → 提升质感的外套 → 配饰。若现有单品足够好，推荐“先不买”，节省资金也是有效成果。

## 采购清单的输出格式
| 品类 | 使用于 A/B/C | 状态 | 目标价格上限 | 购买/试穿关键词 |
|---|---|---|---|---|
| 深灰直筒裤 | A/B/C | 已有 | 新增 0 元 | 检查裤脚堆积 |
| 浅蓝衬衫 | A/B | 待购 | ≤ 220 元（预算目标） | 肩线与领口、透气 |
| 其他…… | … | … | … | … |

三套只是建议组合，**采购表去重之后**才计算总价。商品价格需要实时来源，否则不要写“售价 199 元”“京东有货”等确定话语。

## 现金计算
- 总额仅计算唯一待购项，加必要费用；若上限超预算，删低优先级或找已有替代。
- 发型服务费用通常另计，除非用户明确把理发包含在同一预算中。
- 不建议无计划增加配饰以用完预算。
