# 照片分析协议：只说看得到的

## 输入优先级
1. 全身照：正面站立、双脚可见、衣服尽量不遮挡肩腰的剪裁；并非强制。
2. 正脸照：自然光、清晰头发轮廓、不过度美颜。
3. 可选侧脸、当前喜欢/不喜欢的发型、已有衣服照片。
4. 用户自述的身高、体重、常穿尺码及不适宜的面料：比图像猜测更可信。

## 观察清单

| 项 | 可以谨慎观察 | 不能直接推断 |
|---|---|---|
| 脸部 | 相机角度下可见的脸部轮廓、额头遮挡、面部线条 | 骨相精准分类、具体年龄、性格、健康、族裔 |
| 发型 | 可见长度、发流方向、是否遮挡额头、当前两侧剪裁 | 真实发质、发量密度、发际线变化原因 |
| 上半身 | 可见肩线与服装的关系、衣长、袖长、外套廓形 | 真实肩宽厘米、骨架大小、体脂 |
| 下半身 | 当前裤长、裤脚堆积、裤型与鞋型的视觉关系 | 精确腿长/腰围/臀围/裤码 |
| 肤色 | 当前光线下服装与肤色视觉对比 | 真实色号、肤色冷暖测定结果 |
| 身姿 | 本张照片里明显的站姿及穿衣效果 | 医学体态、健康或人体结构异常 |

## 表达方式
优先写：
- **直接观察**：“照片里目前上衣下摆落在较低位置，可能压缩腰线视觉比例。”
- **可能但待试穿**：“可以尝试更短一点的外套和更顺直的裤腿，现场看是否更协调。”
- **无法确定**：“侧脸未提供，无法可靠判断具体推剪角度；让理发师根据发旋与发质调整。”

避免写：
- “你的身材是标准 X 型，肩宽 43 cm，肤色冷夏。”
- “你看起来 32 岁，所以必须换发型。”
- “照片说明你发量少/生病/没有品位。”

## 输出给用户的小结
先简述当前照片的照明、视角和遮挡影响，再按「可见优势/当前穿搭可优化处/推荐验证方法」提出具体建议。不得以颜值打分。图像不可用时，说明「无法完成本人照片分析」，可继续文字咨询。
