# 能力边界、图片隐私与可选工具

**Skill 是工作流程，不是模型、摄像头、购物 API、图片渲染器或本地网页应用。** 安装后直接使用宿主已提供的模型和工具，不需要单独填写 API Key；但宿主可能有订阅配额、工具权限或上传限制，不能保证各平台能力一致。

## 能力对照
| 需求 | 宿主有能力时 | 宿主无能力时 |
|---|---|---|
| 照片形象分析 | 直接观察用户提供的图片，注明可能误差 | 只做基于文字的穿搭，明确未看图 |
| 发型建议 | 结合可见轮廓和自述发质提供方案 | 依据描述提供候选方向 |
| 本人穿搭效果图 | 用户明确请求且有图像生成/编辑工具时生成，尽量锁定身份与构图 | 给具体可复用生图/修图提示词，不声称生成 |
| 国内电商选购 | 用户提出时用宿主能用的实时搜索验证商品、价格、规格和购买页面 | 给搜索词和选购标准，标注未核验 |
| 衣橱归档 | 仅在用户主动要求、宿主具备可写授权空间时保存 | 不承诺保存，不在公用仓库写用户衣橱 |
| 预算判断 | 分配预算、推荐优先购买项 | 不假定实时价格或库存 |

## 本人换装视觉提示词模板（仅用户请求且工具可用）
“请以用户刚上传的全身照为人物身份与构图基础，保留本人面部识别特征、头身比例、姿态、肤色光照和自然皮肤纹理。将现有服装替换为：[上衣颜色/版型/材质]、[裤子颜色/裤型/裤长]、[鞋款]、[配饰]。发型调整为：[具体发型]。整体符合中国大陆日常真实生活审美，摄影光线自然、衣物褶皱可信、避免美颜和身材重塑。输出为效果模拟，并非真实试穿结果。”

如果宿主只能生成全新图片而非身份一致的编辑，应明确会有相貌变化风险；不要误导用户“100%还原本人”。

## 推荐商品
- 只有实时检索或用户提供的商品详情支持，才能写品牌、型号、标价、优惠、库存、链接。
- 不需要购买时不要主动打开电商，不要未经用户同意下单。
- 如果用户指定淘宝、天猫、京东、唯品会或其他渠道，尊重指定；不暗示每个宿主都能直接访问。
- 以中国本土男性常见版型和气候场景为标准，品牌国别不是好坏依据。

## 隐私和授权
- 人脸照和全身照是敏感的个人视觉素材；请提醒用户不要上传他人的未经授权照片。
- 不自动保存、共享、提交版本库、生成公开链接或发送到其他 AI 服务。
- 宿主为了回答会按照自己的服务机制处理上传文件；不能向用户承诺“绝不会离开设备”。
- 第三方图片编辑、上传、云归档等额外操作，先说明用途与权限，再征得明确授权。
- 不以照片推断受保护或敏感属性，也不做诊断。
