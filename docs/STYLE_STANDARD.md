# PersonalStyling · 中国本土审美标准 V1.1

## 默认定位
中国大陆主流男性审美为主，适度融合日韩简约风。80/20 仅为设计方向的比喻，不是脸部、体型或个人气质的客观测量标准。

## 六条审美原则
1. **清爽自然**：整洁、有精神，拒绝浮夸装嫩和过度精修。
2. **成熟但不显老**：结构适度、得体，避免无差别地推荐西装、油头。
3. **版型优先**：肩线、衣长、腰线、裤长、松量与实际体型匹配。
4. **色彩协调**：低饱和、中性配色优先，但根据用户喜好保留多元风格。
5. **中国生活场景**：高校教学/学术会议、日常办公、通勤、约会、旅行。
6. **购买可行**：优先现有衣物复用，预算人民币，无法验证时不虚构商品价格/库存。

## 观察与限制
- 仅对照片中可见的穿着轮廓、发型状态、相对比例做谨慎推断。
- 不从照片推断身高体重、真实皮肤色号、年龄、人格、收入等。
- 用自然光、正面全身、脸部近照提升参考质量。侧面照可选。
- 照片受镜头、角度、光线影响，不代表真实的体型测量或专业色彩测试。
- 发型须可由中国理发店现实执行，综合脸型、发质、发量及日常维护成本。
- 对真人不做美丑等级评分；如提供评分，仅评估搭配与场景匹配程度，并解释不确定性。

## 三套推荐
A. 日常最优：高频、好打理、适用于主要生活场景。
B. 形象提升：提升利落与正式感，仍保持自然。
C. 年轻清爽：融入少量日韩简约的层次、配色和质感。

每套必须列出上衣、裤子、鞋子、配饰、发型、推荐理由、尺码注意和预算提示。

## 安全与隐私
- 本机模式的照片保存在浏览器当前页面内存中，不自动写入磁盘或上传。
- “AI 看图分析”需要用户主动操作，照片会被发送到用户配置的 API 服务商。
- API 请求禁用 store，仍须遵守服务商自身的数据使用与保留规则。
- README、日志、提交、示例不得包含真实个人脸照或密钥。
